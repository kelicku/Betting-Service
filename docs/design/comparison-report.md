# 参考画像との比較結果と修正記録

## 比較の方法

```bash
node tools/compare/capture.mjs                       # 1440px 幅で全ページを撮影（演出は「最小限」で静止状態）
backend/.venv/bin/python tools/compare/compare.py    # 参考画像と比較
```

- 撮影結果を参考画像の幅（887px）に縮小し、**セクションごとに**参考画像の同じセクションに合わせて並べ、差分を計算する（位置ずれではなく内容の差を見るため）
- 出力：`tools/compare/out/side-by-side.png`（参考画像｜現在｜差分ヒートマップ）、記録：`tools/compare/history.json`
- 差分の値は 0〜100（ぼかし後の平均色差。小さいほど一致）

## 再現できた部分

- 人物（顔・髪・髪飾り・衣装・天球儀・ポーズ）：参考画像から画像編集 API で高解像度化し、背景を透過
- 宮殿の背景：参考画像から人物と文字を除去して再構成
- キャンペーンバナー 3 枚、ガチャカード画像 4 枚、注目の景品 5 点、宝箱パネル、はじめての方へバナー：参考画像の各部分から文字を除いて高解像度化
- レイアウト：ヘッダー、ヒーローの文字配置（キャッチ・タイトル・英字・サブコピー・CTA・実績・縦書き）、バナー 3 枚と矢印、楽しみ方の 4 つのエンブレム、ガチャカード 4 列、注目の景品と宝箱パネル、お知らせ／はじめての方へ、フッター（SNS・リンク・メール登録）
- すべての文字・ボタン・カードは HTML／React で実装（1 枚画像の貼り付けではない）

## 残っている差異

| 差異 | 理由・対応 |
|---|---|
| 実績の数値（参考：会員数 120,000+ など） | 参考画像の数値は架空のため、実データ（API）を表示している |
| ガチャの残り口数（参考：824/1,000 など） | 抽選が行われていないため満数。架空の進捗は表示しない |
| ガチャカードの景品サムネイル | 参考は星形のアイコン。実装は登録されている景品画像を表示 |
| お知らせの件名・日付 | 登録されているお知らせを表示（参考は 2024 年の日付） |
| カード 4 枚目のボタン | 参考は残り 1 口なのに「100回まとめて引く」で矛盾するため、残り口数が足りない場合は「ガチャを引く（1回）」に切り替える |
| タイトル文字の書体 | 参考はより太く装飾的な明朝。Web フォント（しっぽり明朝）で近づけている |
| 見出しのアーチ装飾・左右の水晶 | 参考は 1 枚絵の一部。CSS と生成した装飾素材で近い印象に再現（完全一致ではない） |
| 生成画像の細部 | 参考画像の解像度（887px 幅）からの再構成のため、細部の描き込みは参考と同一ではない |
| ページ全体の高さ | 約 5% 長い。主にセクション見出しとフッターの行間 |
| ヘッダーのロゴ | 参考よりやや小さい（ナビとの幅の兼ね合い） |
