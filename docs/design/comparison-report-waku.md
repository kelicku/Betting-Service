# わくわくガチャ：参考画像との比較結果と修正記録

参考画像：`references/Colorful Fantasy Gacha Game Landing Page.png`（1024 × 1536）
旧デザイン（星降る宝物殿）の記録は [comparison-report.md](comparison-report.md)。旧デザインのソース一式は `.snapshots/before-colorful-redesign.tgz`（Git 管理外）に保存している。

## 決定事項（依頼者に確認済み）

| 項目 | 決定 |
|---|---|
| サービス名 | 「わくわくガチャ」に全体で変更（ロゴ・ページタイトル・メール・規約など）。メールアドレスやクッキー名などの内部の識別子は変更していない |
| 通貨 | 「チケット」を「ポイント（pt）」に表示名を変更。仕組みは同じ。コード・DB 上の名称（`ticket_cost` など）はそのまま |
| 他社のロゴ・商品 | 文字と汎用のイラストで代替。正式なロゴ・商品画像は各社の許諾を得てから管理画面で差し替える |
| 範囲 | トップページ・共通ヘッダー・フッター・スマートフォン下部ナビを明るいデザインに変更。その他のページは従来の暗い配色のまま |

## 残っている差異

| 差異 | 理由 |
|---|---|
| 他社のロゴ（Amazon・Apple・Google Play・デジコ・Nintendo eShop・PlayStation Store）と商品写真 | 許諾が必要なため、文字と汎用イラストで代替（決定事項） |
| ゲーム機・スマートフォン・ギフトカードの画像 | ロゴのない汎用品として生成。形や配色は参考画像と異なる |
| ナビの「ポイント交換」→「景品交換」 | ポイントを直接ギフトに交換する機能はないため、実際の機能（当たった景品の交換申請）に合わせた |
| キャンペーン 3 枚目「貯めたポイントでデジタルギフトと交換！」→「当たった景品は かんたん交換申請！」 | 同上 |
| 遊び方の手順 1・3・4 の文言 | 同上（ポイントを獲得 → ガチャを引く → 景品をゲット → ギフトと交換） |
| 人気の交換先の説明文 | 同上 |
| 人気の交換先の 6 社 | 表示例。実際に用意する景品に合わせて `HomeSections.tsx` の `BRANDS` を変更する |
| 参考画像の「1,000pt」は設定値を表示 | 管理画面の「新規登録特典」の値（開発用データでは 1,000pt） |
| 丸ゴシックの字形 | 参考画像の書体は不明。M PLUS Rounded 1c で近づけている |

## 画像素材

`tools/imagegen/generate.py` の `w_` で始まる 18 点（モデル gpt-image-2.5-sunburst、品質 high）。実費の概算 **$0.75**（1 件はサイズ指定の誤りで API に拒否され、課金なし）。旧デザインの分を含む累計は $1.60。
透過素材は余白を切り詰めて WebP に変換し、アイコンの一覧画像は 1 点ずつに分割した。原本は `tools/imagegen/work/`（Git 管理外）。

## サイト全体への展開（トップページ以外の画面）

- **配色**：Tailwind の色（`night` `moon` `gold` など）を CSS 変数にし、既定を明るい配色に変更（`frontend/src/app/globals.css` の `:root`）。
  ガチャの演出画面だけは `.theme-night` で従来の夜空の配色に戻している。背景にうっすら重ねる色は `veil`（明るい配色では紺、夜空では白）。
- **文字**：見出し・本文とも丸ゴシック（M PLUS Rounded 1c、500・700・900）の 1 書体。明朝体・Cinzel・Zen Kaku Gothic は読み込まない。
- **ボタン**：主ボタンはピンク、2 番目のボタンは青（`components/ui.tsx`）。
- **カーソル**：猫の手（`public/cursors/`、白：通常／ピンク：押せる場所、文字入力欄は通常の I ビーム）。クリックすると肉球のスタンプが一瞬残る（演出「最小限」・動きを減らす設定では出ない）。
- 管理画面も同じ配色になる。古いシードデータの景品画像（夜空のイラスト）と、過去の通知の文面（「チケット」）はデータのため変更していない。

### リンクの確認

全ページをたどってリンク先を確認（未ログイン・会員）。壊れていたのは「最新の当選」から公開終了ガチャへのリンク（404）で、公開中のガチャ以外はリンクしないよう修正した。
ヘッダーのメニューに「抽選履歴」「通知」を追加、「人気の交換先」のタイルからガチャ一覧へリンク。

### 表示速度（1440px、2 回目の表示）

| ページ | 変更前：合計 / JS | 変更後：合計 / JS |
|---|---|---|
| トップ | 4,126KB / 1,584KB | 2,331KB / 647KB |
| ガチャ詳細 | 3,627KB / 1,577KB | 1,873KB / 635KB |
| ログイン | 3,270KB / 1,562KB | 1,573KB / 623KB |

主な対策：全ページで読み込んでいた 3D の星空背景（Three.js 約 900KB）を廃止（3D はガチャの演出画面でだけ読み込む）、
ThreeBoundary を Three.js に依存しないファイルに分離、フォントを 1 書体 3 太さに削減、小さな画像を表示サイズで配信。
Cloudflare のトンネル経由では、トップ 約 1.6 秒・その他 約 0.7 秒で表示完了。
バックエンドの停止に 10 秒かかっていた問題（起動コマンドが終了の合図を受け取れなかった）を修正し、再起動は 約 18 秒 → 約 7 秒。

## メインビジュアルの背景を和の風景に変更（参考画像からの意図的な変更）

日本の利用者向けに、背景を「桜・富士山・白壁のお城・五重塔・朱色の鳥居・太鼓橋・提灯」の春の風景に変更（`public/images/waku/hero-bg-jp.webp`、
生成ジョブ `w_hero_bg_jp`、約 $0.05）。構図（左は明るく文字が読みやすい、右下は猫を置く余白、下端は桜と雲で下のセクションになじむ）と配色は従来どおり。
スマートフォンではお城と鳥居が見える位置で切り抜く。宝箱の猫は約 15% 小さくした（1440px 幅で画面幅の 51% → 44%）。
